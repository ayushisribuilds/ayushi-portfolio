# Ayushi Srivastava — Performance Marketing Portfolio

Static portfolio website built from `index.html` and the `assets/` directory.

## Deploy on Railway

This repository includes a small Nginx container configuration for serving the site. In Railway, create a service from this GitHub repository and deploy from the `main` branch. Railway will detect the `Dockerfile`. Generate a Railway domain for the service to make the site public.

Keep this source repository private if you prefer; the deployed website itself will be publicly accessible through its Railway domain.
